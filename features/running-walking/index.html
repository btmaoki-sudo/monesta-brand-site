運動前のお悩み

  • 何を揃えればいいかわからない
  • 日中の日差しが気になる
  • 貴重品をどう持ち歩くか迷う
02 / DURING

運動中のお悩み

  • 長時間歩くと足元が気になる
  • できるだけ快適に走りたい
  • 身につけるものは邪魔になりにくい方がいい
03 / AFTER

運動後のお悩み

  • 帽子やシューズのお手入れが面倒

シーンに合わせたMONESTAのアイテムでサポートします。
